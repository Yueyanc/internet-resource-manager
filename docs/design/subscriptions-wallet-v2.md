# 订阅管理 UI 概念稿 · Wallet V2

产物：`subscriptions-wallet-v2.png`。使用内置 image_gen 编辑 V1 设计图生成；仅出图，未修改应用代码。

## 反馈与方向

V1 的多色玻璃背景过于杂乱，订阅仍像信息面板。V2 收敛配色，并改为实体会员卡式卡面。

## 提示词摘要

仅参考 V1 的品牌、中文导航与功能结构，重做订阅卡片的视觉语言。
使用瓷白、冷银灰、石墨黑，保留少量深绿色交互强调。去除彩虹渐变和多色光晕。
订阅卡片类似高级实体会员卡，约 1.586:1 横向比例，大圆角、精细边缘、轻微厚度、
细腻磨砂或拉丝材质、柔和定向反光与真实接触阴影，正面整齐排列为两列三行。
卡面突出单色品牌图形、服务名称、价格，只在底部保留小号续费日期与支付标识。
移除卡面内的分类标签、进度条、字段图标行及操作按钮栏，将操作移到卡外或更多菜单。
顶部统计使用轻量无框分栏，右侧日历与分类花费保持简洁，不抢卡片视觉重心。

## 使用边界

- 设计图中的订阅与金额为概念展示，不得用作运行时种子数据。
- 文生图中的文字、日期及数据需在开发中重新核对，不能代替真实计算逻辑。
- 本稿保留 V1 原图，不覆盖此前的设计探索。
