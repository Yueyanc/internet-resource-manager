## 提示词摘要

为 IRM / 资源管家的中文订阅管理工作台生成一张高保真桌面端 UI 设计稿。
保留两级侧边导航、全局新建、四项费用统计、两列订阅卡片、到期日历及分类花费。
采用浅色珍珠白和薄荷绿底色，融合青绿色渐变、少量淡紫与浅杏色边缘光。
使用磨砂半透明玻璃、大圆角卡片、细白色高光描边、柔和投影和漫射光效。
保持 antd 风格控件的比例与辨识度；深色清晰文字、细线图标、紧凑有序的信息层级。
卡片圆角约 16–20px，控件约 8–10px。避免霓虹、粒子、光球、设备外框与营销式构图。
展示 ChatGPT、Claude、iCloud、Spotify、Cloud VPS、Figma 六张概念订阅卡。

- 图中资源和金额为设计展示内容，不是实际用户数据，不能作为运行时演示种子。
